# Отложенный бот ttView3

`ttView3` временно исключён из сборки, потому что сейчас не используется и зависит от двух локальных патчей ядра:

- передача `Alor avgPrice` в `PositionOnBoard.EntryPrice`;
- флаг `ParamGuiSettings.CustomTabsFirst`.

## Содержимое

- `ttView3.cs.disabled` — исходник бота из старой ветки `tt/my-work`, снимок `a6739929106630e44f2de3131f0e1dae7066a320`;
- `ttView3_CORE_PATCHES.patch` — компактная копия двух необходимых патчей ядра.

## Как вернуть бота

1. Проверить патчи по `LOCAL_PATCHES.md` на актуальной версии автора.
2. Вручную адаптировать или применить изменения из `ttView3_CORE_PATCHES.patch`.
3. Переименовать `ttView3.cs.disabled` в `ttView3.cs`.
4. Собрать `OsEngine` и проверить вкладку `View` и среднюю цену Alor.

Не переименовывать файл в `.cs`, пока оба патча ядра не восстановлены: иначе проект не соберётся.
